# File atlas: why each file exists

This is the map for the [exact copyable source](copyable/README.md). Each link opens the complete file you can paste into the same relative path in a new project. Read the relevant lesson first; this atlas then tells you what to look for in each file. The [core block walkthrough](09-core-code-blocks.md) explains the longest files in more detail. A file usually has four blocks in order: **imports** (dependencies), **types/constants** (shape and fixed rules), **functions/components** (work it performs), and **exports** (what other files may use). SQL migrations use a different sequence: schema changes, constraints/policies, function body, then permissions.

## Files intentionally absent from the copyable snapshot

Downloaded `node_modules/`, `.env.local`, personal credentials, built `dist/`, binary sprites/music/cries, and the large public animation asset data are not copied. Install dependencies with npm; create your own environment file; obtain media from authorized sources or replace it. The [snapshot manifest](copyable/SNAPSHOT-MANIFEST.md) lists exactly what is present.
